# gifpaint cloud backend

## Shape
- Static Vite build + Vercel Node functions (`api/*.js`, web-standard `export const GET = …(request)`).
  Non-Next Vercel functions match ONE path segment: Better Auth lives in `api/auth.js` and
  `vercel.json` rewrites `/api/auth/(.*)` → `/api/auth?__ba=$1`; `restorePath` (`api/_lib/http.js`)
  rebuilds the pathname. `:path*` in a rewrite destination query is rejected by Vercel's matcher.
- `api/_lib/db.js` one `pg` Pool on `globalThis` (Neon pooled URL) shared by Better Auth and `q()`.
- `api/_lib/auth.js` Better Auth: `baseURL.allowedHosts` (prod, `gifpaint-*-zakros.vercel.app`,
  `localhost:*`), OAuth providers only when env keys exist, `rateLimit.storage: 'database'`.
- `api/_lib/validate.js` is pure (no env/DB) — every trust rule lives here and is pinned in
  `test/api.test.mjs`. Asset URLs: `B2_PUBLIC_URL/` prefix, GIPHY media hosts, picsum only.
- Visibility `private|unlisted|public`; non-owners get 404 (not 403) for private; soft delete.
- `src/cloud.js`: lazy `createAuthClient()`, `api()` (non-JSON 200 = no API, e.g. plain `vite`),
  `uploadDataSources` swaps `data:` URLs in place on the live `sources` entries (upload once),
  thumbnail upload is best-effort. `main.js` owns UI: `cloud` state, `requireUser()` waiter queue.

## UI grammar (north stars: /Users/naeluh/wwww/Kuzic, /Users/naeluh/wwww/oss-design-prototype)
- Read the pattern in both repos before adding any surface (Kuzic `src/components/ui/SURFACES.md`,
  `DESIGN.md`, `.agents/memory/*.md`; prototype `docs/PROTOTYPE-GUIDE.md`). Kuzic owns tokens,
  the prototype contributes interaction; keep gifpaint's lowercase labels.
- Sheets = `<dialog class="sheet">` + `.sheet-inner` (`openSheet`, `whenClosed`, `confirmSheet`,
  `askName` in main.js). Never `prompt`/`confirm`/`alert`. Menus = `[popover].menu` + `openMenu`.
- Ember only on the commit button; `.danger` only on destructive commits; destructive menu items
  last behind a hairline. Copy: "couldn't X. <next move>", no em dashes, no exclamation marks.
- Anything appended to the page while a modal is open must go INSIDE the open dialog (the rest
  is inert): the copy fallback textarea failed until it did.
- Headless probes: script `.click()` has no user activation, so clipboard/execCommand fail —
  use CDP `Input.dispatchMouseEvent` for anything gated on activation. Check `hidden` by computed
  `display`, never the attribute.

## Workflows
- Schema: `db/auth.sql` generated by `bunx auth@latest generate --config api/_lib/auth.js --output db/auth.sql`
  (`@better-auth/cli` is deprecated); app tables in idempotent `db/schema.sql`. Apply with
  `neon psql -- -v ON_ERROR_STOP=1 < file`.
- Local full stack: `set -a; source .env.local; set +a; vercel dev --listen <port>` — `vercel dev`
  did NOT load `.env.local` itself (pg fell back to localhost:5432). Check the port owner first.
- Probe API with curl + cookie jar + `Origin` header (Better Auth CSRF). Delete probe users after
  (`delete from "user" where email like 'e2e-%'` — cascades to projects/uploads).
- UI proof without the browser extension: headless Chrome + CDP from Node (handle
  `Page.javascriptDialogOpening` for the name prompt / copy-link prompt).
- Deploy: `vercel deploy` = preview; verify with `vercel inspect` (target) and
  `vercel curl <path> --deployment <url>` (Deployment Protection 302s anonymous curl).
- Presigned PUT: aws4fetch needs `aws: { signQuery: true, allHeaders: true }` or Content-Type /
  Content-Length are silently NOT signed; set `X-Amz-Expires` explicitly (default 86400).

## Open (deferred)
B2 objects of soft-deleted projects / failed saves are not swept (`uploads` table lists them);
no account deletion; no email verification (gallery spam ⇒ add verification); B2 size
enforcement of the signed Content-Length is unproven until B2 keys exist.
